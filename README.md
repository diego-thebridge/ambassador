# diegodl — Anthropic Education Ambassador, Madrid

Página personal: recursos para empezar con Claude, contacto y mis charlas.
Sitio estático de un fichero, publicado con GitHub Pages.

Los eventos de la comunidad de Madrid están en
[claudemadrid.com](https://claudemadrid.com).

## Puesta en marcha

1. Crear un formulario en [formspree.io](https://formspree.io) y sustituir
   `PON_AQUI_TU_ID_FORMSPREE` en `index.html` por el endpoint que dan.
2. Settings → Pages → Deploy from a branch → `main` / root.

El contenido del Radar está en `noticias.js`.

Para trabajar en local basta con abrir `index.html`, o:

```bash
python3 -m http.server 8000
```

Las convenciones del repo y las reglas de marca del programa Claude Community
están en [`CLAUDE.md`](CLAUDE.md). Léelas antes de tocar textos o añadir
imágenes.
